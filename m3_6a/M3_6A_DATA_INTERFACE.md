# Read-only data interface

`AcceptedData` reuses the unchanged M3.5A Release validator, pinned to the authoritative M3.4 approved index and SHA256303d5570d78ecbf1276459d99be6ed1420ccfb49b8f6c6224f38019bfe024a5a. It verifies native/source/archived acceptance bindings and complete visualizations before returning samples. There are12 accepted train trajectories,3709 states,3697 transitions; no held-out experiment exists here. Planned, partial, historical and alias IDs are rejected. Mechanical-equivalence keys and family partitions are checked; trajectory identity and family remain in proof metadata. No neighboring states are repartitioned.

Directly saved: x/rho/g_rho/g_x shaped(T,H*W), u shaped(T,2*(H+1)*(W+1)), scalar histories, iteration and outgoing changes; problem coordinates, connectivity, nodal force vector, zero fixed DOFs, material/SIMP/filter/OC/stopping descriptors and provenance. See the exact field inventory in evidence/20261015_architecture_v1/data_field_audit.json and preimplementation audit. These are nondimensional solver quantities in declared coordinate/force units, not asserted SI units. Compliance is force·displacement; gradients are compliance per dimensionless density; u is displacement. Filter radius is saved in grid-cell units; descriptor axes use radius*dx and radius*dy, preserving the documented grid-distance filter rather than asserting a new isotropic physical filter.

Deterministically reconstructed: Cartesian element/node field views, fixed-DOF component indicators, full rectangular active mask from declared complete connectivity, dx*dy quadrature, causal history indices and saved-state delta targets. Arrays reshape C(nely,nelx); row increases physical y. Nodes are row-major with alternating x/y DOFs. Physical rho is filtered density; x is the design variable with the OC volume budget. Never infer geometry from small rho.

Mode A element_history[K,1,H,W] is x only; node_history[K,0,H+1,W+1] is empty. Mode B is explicit and separate: element channels x,rho,g_rho,g_x,spatially broadcast compliance; node_history[K,2,H+1,W+1] is displacement. Only history through t is extracted. Saved mechanical fields use unchanged M3.5A training-state0 RMS and force scaling (u/F, compliance and gradients/F²); normalization is loaded and verified, never fitted. Mode A has analytical scaling only. Mode B needs mechanical inputs at deployment and is not FEM-free.

Static node_fields[4,H+1,W+1] are raw Fx,Fy,bx,by. Element/node coordinates remain separate physical arrays. Global19 descriptors are named in data.GLOBAL_NAMES; dimensions/filter lengths divide by an explicit48-unit reference, force/lambda use log1p and positive OC/stopping widths use log10. Operator coordinates divide isotropically by max(width,height). No realized termination length, future metric or target-derived statistic is an input; configured cap is known a priori.

`example(pid,t,k,h,mode)` keeps the available causal suffix without repeating initial states; h is1/5/10 and t+h must exist. `collate` right-pads time and bottom/right-pads native space with explicit masks; no resampling. Returned target/proof are separate from model input access. Memory maps are opened one trajectory at a time; returned samples copy only requested histories/target.

Unavailable/reserved: accepted L/MBB/bridge histories, inactive/passive masks, nonzero prescribed values, traction/body-force descriptors and accepted held-out families. The current adapter intentionally supports verified full rectangles only. Synthetic masked fixtures never enter accepted data.

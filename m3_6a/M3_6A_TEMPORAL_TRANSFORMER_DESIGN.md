# Causal temporal Transformer

Every saved history state is spatially encoded independently into32 anchor tokens. The temporal module sees B*M sequences of lengthK and width24; it does not flatten all native elements into Transformer tokens. One four-head Transformer layer uses an upper-triangular causal attention mask, a right-padding key mask and dropout0. No pooling destroys all spatial structure: each anchor retains its own causal temporal sequence; cross-anchor exchange occurs in the spatial stage, not temporal attention.

Position features are [iteration/cap, elapsed_iteration/cap, sin(2π iteration/cap), cos(2π iteration/cap)], projected to width24. Cap is the original known optimization cap, not the realized future trajectory length. Histories are nonempty strictly increasing saved iterations and may have different valid lengths. The decoder uses only the last valid latent and spatial skip, with [h/10,log1p(h)] horizon embedding. Horizons1/5/10 never access future input fields; target x[t+h] is consumed only by external loss/diagnostics.

Tests change later history values and compare earlier temporal outputs, check invariance to garbage in padded history slots, and poison target values while checking unchanged forward results. Synthetic histories1/2/4 and real histories1/3/2 are exercised. Attention cost is O(B*M*K²), preserving more spatial detail than a single global token while avoiding element-level temporal attention. Fixed anchors may miss localized dynamics, and independent per-anchor attention does not learn unrestricted cross-location time interactions. These are explicit capacity tradeoffs, not demonstrated scientific advantages.

# M3.6A

Start with [final report](M3_6A_FINAL_REPORT.md), [architecture](M3_6A_ARCHITECTURE_SPEC.md) and [data interface](M3_6A_DATA_INTERFACE.md). This package performs no FEM/OC or optimizer steps.

From the repository root with the existing environment:

```bash
OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=16 OMP_NUM_THREADS=16 PYTHONDONTWRITEBYTECODE=1 /users/atabarra/.venv/bin/python -m m3_6a.example
```

The default read-only data adapter verifies authoritative acceptance plus all complete visualizations before returning causal samples. Full verification decodes3709 GIF frames and can take several seconds.

Open [Jupyter viewer](visualizations/20261015_complete_v1/trajectory_viewer.ipynb) or [standalone HTML](visualizations/20261015_complete_v1/trajectory_viewer.html). Individual PNG/GIFs and manifests are under visualizations/20261015_complete_v1/trajectories/. See [visualization contract](M3_6A_VISUALIZATION_CONTRACT.md).

The example is untrained and reports shapes only; prediction values carry no physical acceptance. All12 data trajectories are train-only architecture diagnostics. Future accepted-index integration is a separate controlled change.
